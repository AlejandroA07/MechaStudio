# Plan & Train Glossary

## Exercise

A reusable movement definition with a name, optional description and media, and source information. An Exercise does not contain timing or repetitions.

## Step

One instruction within a Block. A Step is either an Exercise with a duration, repetition count, or untargeted completion, or an explicit timed Rest.

## Block Template

A reusable, named sequence of Steps with a category and default repeat count. The interface calls these items Blocks.

## Block

An editable copy of a Block Template placed inside a Routine. Changes to the copy do not alter the template or another Routine.

## Routine

A saved, ordered arrangement of Blocks that can be started as a Session or placed into a Plan.

## Session

One scheduled or performed occurrence of a Routine. Starting a Session captures an immutable snapshot of the Routine.

## Session Runner

The focused interface that guides an active Session. It advances timed Steps, waits for manual completion of repetition or untargeted Steps, and exposes pause and navigation controls.

## Plan

A dated schedule, lasting one to fifty-two weeks, containing independently editable Planned Sessions.

## Profile

A private member workspace in the hosted application. Exercises, Blocks, Routines, Plans, media, and Session history belong to exactly one Profile unless promoted into the shared catalog.
